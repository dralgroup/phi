# Calculations for "Photochemical N-dealkylation of Tertiary Amines Coupled with Photocharging of Poly(Heptazine Imides)"

This repository contains computational material in the interactive Jupyter notebook supported by the MLatom program used for generating and analyzing the calculations in the study:

Jingru Zhuang, Quanhao Zhang, Chong Wang, Tao Yao, Cheuk Lok Cheng, Pavlo O. Dral*, Oleksandr Savateev*. Photochemical N-dealkylation of Tertiary Amines Coupled with Photocharging of Poly(Heptazine Imides). *Angew. Chem. Int. Ed.* **2026**. DOI: https://doi.org/10.1002/anie.202522677.

You can also browse the html version of the Notebook with calculations and 3D view of calculated species at http://mlatom.com/misc/phi.html.

Data files can be found on FigShare at https://figshare.com/s/50967e320e06c8c922f6.
